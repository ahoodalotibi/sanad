# D3 — Urdu Quran translation (`ur`)

Put here:
- `original/` — the translation file exactly as downloaded
- `quran_ur_<edition-slug>.csv` — optional if the original is already structured
- `edition.json` — **required** (who translated, who published, why it is approved)

Full column specification, `edition.json` template and validation rules:
see [`../README.md`](../README.md).

Approval rule: the edition must be **published by the King Fahd Complex** or **listed on quranpedia.net**.
