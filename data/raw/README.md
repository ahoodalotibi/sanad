# SANAD — raw source files

This folder receives **original source files only**. Nothing here is typed, edited,
translated or generated by hand or by an AI. Import scripts read these files,
validate them, and load them into Supabase as `draft` / `pending_review` rows.

## Rules for every file

1. **Keep the original.** Put the file exactly as downloaded into the folder's
   `original/` subfolder. Never edit it.
2. **No manual retyping or "fixing" of religious text.** If the original is
   XLSX / XML / JSON / SQL, leave it as is — a conversion script will produce the
   CSV and prove (by counts and checksums) that nothing changed.
3. **Encoding:** UTF-8. CSV files: comma-separated, header row, fields quoted when they
   contain commas, quotes or line breaks.
4. **Provenance file is mandatory:** each dataset folder needs a `SOURCE.md`
   (or `edition.json` for translations) saying where the file came from.
5. **Approved sources only** — as defined in «المرجعية والحزمة العلمية والبيانات»
   (version 1448/3/20), pages 3–4.

Each folder's `README.md` has the exact file names and columns.
