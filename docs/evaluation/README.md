(المدوّنة المعتمدة 13,892 نصًا + Gemini 3.5 Flash-Lite للفهم والاختيار فقط). السجل الكامل: [guide-run-2026-10-05.log](guide-run-2026-10-05.log).

ملاحظات:
- أجوبة «بينات» منشورة بالعربية فقط؛ تظهر للسائل بغير العربية مع تنبيه وعرض التحويل لداعية بلغته.
- ملف الحالات المنقول من الدليل فيه 10 حالات، والدليل يذكر 12؛ تُضاف الحالتان عند توفر نصهما.
- دون النموذج يعرض الموقع فقط سؤالًا منشورًا أو مصطلحًا يطابق السؤال نفسه ولا يعرض حديثًا أبدًا، وغير ذلك يُحال.
