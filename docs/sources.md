# مصادر المحتوى وطريقة الاستيراد

كل محتوى سَنَد يأتي من المصادر المذكورة في «المرجعية والحزمة العلمية والبيانات» (نسخة 1448/3/20).
السكربتات **تستخرج** النص المنشور كما هو؛ لا تولّد ولا تترجم ولا تلخّص محتوى دينيًا.
كل ما يُستورد يدخل القاعدة كمسودة (`draft` / `pending_review`) ولا يظهر للمستخدم قبل مراجعته.

## 1. الجمهرة — معجم المصطلحات الشرعية
- المصدر في الدليل: ص4، «الترجمة والمصطلحات» — https://islamic-content.com/dictionary
- طريقة الجلب: لا توجد واجهة برمجية موثقة؛ نقرأ الصفحات العامة:
  `/dictionary` ← التصنيفات الثمانية ← `/dictionary/term/{id}` ← `/dictionary/word/{id}` ← الترجمات `/dictionary/word/{id}/{lang}`.
- الترجمات تُكتشف من قائمة «ترجمة هذا المصطلح متوفرة باللغات التالية» في صفحة كل مصطلح، دون افتراض لغات.
- حقوق الاستخدام: «يحق الاستفادة العلمية في الاستخدام الشخصي غير التجاري» — https://islamic-content.com/page/copyright
- الجداول: `documents` (لكل مصطلح ولغة)، `knowledge_chunks` (لكل قسم منشور: «من معجم المصطلحات الشرعية»، «من موسوعة المصطلحات الإسلامية»، «من الموسوعة الكويتية»)، `terms`، `term_translations`.
- **المعاني لا تُدمج:** كل قسم تعريف قطعة مستقلة بمصدره ومجالاته (التصنيفات) ومراجعه؛ وكل قسم مترجم مربوط بالقسم العربي المقابل له (`translation_of_section`). `usage_guideline_ar` يبقى فارغًا عند عدم نشره، وضوابط الدليل العشرة تبقى مطبقة في النظام.

```bash
npm run ingest:dictionary -- --limit=20     # دفعة تجريبية
npm run ingest:dictionary -- --all          # المعجم كاملًا (حوالي 14 ألف مصطلح + ترجماتها)
npm run ingest:load -- --source=dictionary --dry   # تجربة الإدخال في الذاكرة
npm run ingest:load -- --source=dictionary         # الإدخال في Supabase (يتطلب المفاتيح)
```
المخرجات: `data/ingest/jamharah-dictionary/entries.jsonl` و`report.json`. الصفحات الأصلية تُحفظ دون تعديل في `raw/` (غير مرفوعة إلى المستودع).

## 2. بيّنات: أسئلة وأجوبة عن الإسلام (مركز أصول)
- المصدر في الدليل: ص4، «الشبهات والأسئلة المتكررة» — https://dawa.center/file/7937 (PDF، مركز أصول 2024، 1259 صفحة).
- **لماذا لا نستخرج من ملف PDF:** طبقة النص فيه تالفة عند الاستخراج (مثل «اإليمان» بدل «الإيمان»، «اهلل» بدل «الله»، «ملسو هيلع هللا ىلص» بدل ﷺ)، والآيات مكتوبة بخط خاص فلا تُستخرج إطلاقًا. الاستخراج المباشر ينتج نصًا دينيًا غير مطابق للمنشور.
- **من أين نأخذ النص:** مقدمة الكتاب (ص21 من ملف PDF، فقرة «هذا الكتاب») تذكر أن المشروع نشر الأسئلة والأجوبة على منصة bayenat.net/ar **ثم انتقى أهمها** في الكتاب. نقرأ من المنصة **مؤلفات مركز أصول فقط** (`/ar/sources/11`، 263 مسألة) (قرار الفريق بتاريخ 2026-10-05).
- **حدود النسبة:** المصدر يُسجَّل باسم «منصة بينات — مؤلفات مركز أصول»، وكل مادة تحفظ رابط صفحتها ورقمها على المنصة، وعلاقتها بالكتاب (`related_book`: الرابط، نوع العلاقة، الدليل من المقدمة، `inBook: unverified`). **لا نقول إن المادة من الكتاب، ولا ننسب لها رقم صفحة**؛ لأن الكتاب منتقى من المنصة وليس كل ما فيها.
- كل مسألة: نص السؤال، عبارات مشابهة للسؤال، مختصر الجواب، الجواب التفصيلي، المؤلف والمصدر، الاقتباسات (آيات بمراجعها، وأحاديث بتخريجها)، وروابط الترجمات من تبويب «ترجمات».
- الترجمات: عند الفحص كانت مسائل مركز أصول بالعربية فقط؛ السكربت يكتشف أي ترجمة تظهر لاحقًا تلقائيًا.
- الجداول: `documents` (لكل مسألة ولغة، `external_ref = bayenat:{id}`)، `knowledge_chunks` (القطعة 0: السؤال + العبارات المشابهة + مختصر الجواب؛ ثم الجواب التفصيلي مقسّمًا عند الأسطر فقط، وكل قطعة تبدأ بالسؤال).

```bash
npm run ingest:bayyinat -- --limit=10     # دفعة تجريبية
npm run ingest:bayyinat -- --all          # كل مسائل مركز أصول
npm run ingest:load -- --source=bayyinat --dry
npm run ingest:load -- --source=bayyinat
```
المخرجات: `data/ingest/bayyinat/qa.jsonl` و`report.json`.

## إعادة التشغيل
- الصفحات المحفوظة في `raw/` تُعاد قراءتها بدل تنزيلها مرة أخرى (`--refresh` لإعادة التنزيل).
- الإدخال يطابق المستندات على (المصدر، `external_ref`)؛ غير المتغير يُتخطى، والمراجَع أو المنشور لا يُستبدل أبدًا.
