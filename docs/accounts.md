# الحسابات، «أسئلتي»، وبوابة الجمعية

## الرحلة
1. السؤال لا يجد نصًا معتمدًا، أو حالة شخصية، أو طلب السائل شخصًا ← الواجهة تعرض «أرسل سؤالك لداعية بلغتك».
2. السائل يسجّل الدخول برمز يصله على بريده (Supabase Auth) ← `POST /api/referrals`.
3. يظهر السؤال في بوابة الجمعية **فقط** للدعاة الذين يتحدثون لغته (`GET /api/daee/queue`)، دون أي بيانات عن السائل.
4. يأخذه داعية واحد (`claim`) فلا يراه غيره كسؤال مفتوح، ثم يرد (`answer`).
5. يظهر الرد في «أسئلتي» (`GET /api/my/referrals`).

## الصلاحيات
- كل الكتابة في قاعدة البيانات من الخادم بالمفتاح السري بعد التحقق من جلسة المستخدم؛ RLS تبقى مفعّلة كخط دفاع ثانٍ.
- السائل يرى أسئلته فقط. الداعية يرى الأسئلة المفتوحة بلغاته وما أخذه هو فقط. المشرف يضيف الدعاة ولغاتهم.
- لغة جديدة تُضاف تلقائيًا لجدول اللغات عند أول سؤال بها.

## أول مشرف
```
npm run admin:grant -- --email=you@example.com
```
بعدها يضيف المشرف الدعاة من صفحة الإدارة (البريد، الاسم، اللغات).
